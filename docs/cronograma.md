# Cronograma por dependências

Plano de trabalho da Entrega Parcial 1, sem atribuir datas retroativas ou prazos institucionais não fornecidos.

| Etapa | Dependência | Evidência de conclusão |
|---|---|---|
| 0. Auditoria inicial | Arquivos oficiais disponíveis | Integridade e compatibilidade verificadas |
| 1. Pré-projeto | Auditoria | Delimitação, problema, hipóteses e metodologia documentados |
| 2. Viabilidade | Pré-projeto | Restrições técnicas, operacionais, de dados e manutenção |
| 3. Requisitos e aceite | Viabilidade | Requisitos mensuráveis e verificações associadas |
| 4. Casos de uso e diagramas | Requisitos | Fluxos e modelo compatíveis com o dataset |
| 5. Estrutura do pipeline | Contrato de dados | Módulos e testes de entrada |
| 6. Organização dos dados | Auditoria aprovada | Cópias e documentação com integridade preservada |
| 7. ETL | Estrutura e dados oficiais | Base tratada, relatório e testes |
| 8. EDA | Base tratada validada | Notebook executado, gráficos e interpretação |
| 9. Reprodutibilidade | ETL e EDA | Instruções testadas e relatório de validação |

O Dataset Gate foi resolvido pela inspeção dos arquivos oficiais fornecidos, sem gerar nova base. Os commits devem registrar unidades concluídas e respeitar intervalo real mínimo de 30 minutos entre commits desta execução. O controle de horários é temporário, fora dos entregáveis permanentes.

Fase posterior: obtenção autorizada de dados reais, validação com usuários, engenharia de atributos, baseline temporal, avaliação de modelos e eventual interface integrada. Não faz parte da Entrega Parcial 1.
